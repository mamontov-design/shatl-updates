# Shatl Updates

This repository serves in-app updates for Shatl only: the official Sparkle
update feed, its release notes, and the update archives Shatl downloads.

To download Shatl, use the
[latest release](https://github.com/mamontov-design/Shatl/releases/latest) of
the main repository.

- Update feed:
  `https://mamontov-design.github.io/shatl-updates/appcast.xml`
- Source code:
  `https://github.com/mamontov-design/Shatl`
- Update archives:
  `https://github.com/mamontov-design/shatl-updates/releases`

`appcast.xml`, update archives, and linked release notes are generated with the
official Sparkle publishing tools. Update archives are signed with EdDSA, and
the appcast itself is signed. Generated signed files must not be edited
manually.

This repository does not contain the Sparkle private signing key.
