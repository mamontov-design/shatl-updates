Shatl 1.0

The first public release of Shatl.

  • Native torrent downloads from magnet links and .torrent files.
  • File selection, download-folder management, and session restoration.
  • Native macOS interface with multiple languages and appearance options.
  • Secure in-app updates powered by Sparkle.

Shatl 1.0

Первый публичный релиз Shatl.

  • Нативная загрузка торрентов по magnet-ссылкам и из .torrent-файлов.
  • Выбор файлов, управление папкой загрузки и восстановление сессии.
  • Нативный интерфейс macOS, локализации и настройки внешнего вида.
  • Безопасные обновления внутри приложения на базе Sparkle.
